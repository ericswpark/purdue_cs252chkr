# cs252chkr

Retrieves and displays useful metadata about the repository for grading purposes

Example (from this repository, oh so meta):

```
Initial commit was made at 2025-02-03 20:38:29 (a week ago)
=============
| Eric Park |
=============
Commits: 35 commits
Time spent: 3 hours and 24 minutes
LOC: +2625/-206 (7.85%) (!)
```

## Building

- Install `rustup`
- Install the Rust compiler and toolchain with `rustup`
- Build a release executable using the following command:

```
cargo build --release
```
